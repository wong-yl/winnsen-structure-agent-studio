## ⚙️ 脚本功能

### 自动化流程

对每个SLDDRW文件：

1. ✅ **打开图纸** - 静默模式
2. ✅ **检查类型** - 判断是否为钣金件
3. ✅ **导出DXF** - 展开视图（AutoCAD 2013格式）
4. ✅ **导出PDF** - 展开视图（车间参考）
5. ✅ **关闭图纸** - 自动清理

### 智能特性

- **断点续传** - 可随时中断（Ctrl+C），再次运行会跳过已完成的文件
- **进度保存** - 进度记录在 `.flatpattern_progress.json`
- **错误恢复** - 单个文件失败不影响其他文件
- **日志记录** - 详细日志保存到 `展开图导出日志_<时间戳>.json`
- **非钣金跳过** - 自动识别并跳过非钣金零件

## 🔧 故障排查

### 问题1：无法连接到SolidWorks

**症状**：`❌ 错误：无法连接到SolidWorks`

**解决**：
1. 确认SolidWorks已启动
2. 重启SolidWorks（以管理员身份）
3. 检查防火墙是否阻止了COM连接

### 问题2：部分文件导出失败

**症状**：`❌ DXF导出失败`

**原因**：
- 文件可能损坏
- 缺少展开视图
- 文件被锁定

**解决**：
1. 手动打开失败的文件检查
2. 查看日志文件中的详细错误信息
3. 可以跳过失败的文件，继续其他文件

### 问题3：DXF文件无法在AutoCAD中打开

**症状**：AutoCAD报错

**解决**：
- 脚本使用 AutoCAD 2013 格式（兼容性最好）
- 如需其他版本，修改脚本中的版本参数

### 问题4：进度文件丢失

**症状**：重新运行从头开始

**解决**：
- 进度文件：`.flatpattern_progress.json`（隐藏文件）
- 可以手动删除此文件强制重新处理所有文件

## 🎯 工作台集成逻辑（记录用于后续自动化）

### 批量导出流程

```python
# 伪代码
for each slddrw_file in order_directory:
    1. 检查是否已处理（进度文件）
    2. 打开SolidWorks文档（静默模式）
    3. 判断是否为钣金件
       - 检查 SheetMetal 特征
       - 检查 FlatPattern 特征
       - 检查文件名（*_FLAT.SLDDRW）
    4. 导出DXF（使用ExportToDWG2方法）
    5. 导出PDF（使用SaveAs方法）
    6. 关闭文档
    7. 更新进度文件
    8. 记录日志（成功/失败/跳过）
```

### 关键API

- **打开文档**：`sw.OpenDoc6(path, type, options, config, errors, warnings)`
- **导出DXF**：`model.ExportToDWG2(dxf_path, map_path, version, export_all, data, ...)`
- **导出PDF**：`model.Extension.SaveAs(pdf_path, save_as_version, options, data, errors, warnings)`
- **关闭文档**：`sw.CloseDoc(path)`
