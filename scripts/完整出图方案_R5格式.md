## 🎯 工作台集成逻辑（试点记录）

本次方案包含两个关键流程：

### 1. 图纸属性批量更新

```python
for each slddrw_file:
    1. 备份原文件
    2. 打开SLDDRW文档
    3. 获取自定义属性管理器
    4. 更新签字栏属性（DrawnBy, CheckedBy, etc.）
    5. 更新日期属性（DrawnDate, CheckedDate, etc.）
    6. 更新版本属性（Revision, Description, etc.）
    7. 保存文档
    8. 关闭文档
```

**关键API**：
- `model.Extension.CustomPropertyManager("")`
- `mgr.Get5(prop_name, use_cached, val, resolved, was_resolved)`
- `mgr.Set2(prop_name, value)`
- `mgr.Add3(prop_name, type, value, option)`

### 2. 钣金展开图批量导出

```python
for each slddrw_file:
    1. 打开SLDDRW文档
    2. 判断是否为钣金件
    3. 导出DXF（使用ExportToDWG2）
    4. 导出PDF（使用SaveAs）
    5. 关闭文档
    6. 更新进度文件
```

**关键API**：
- `sw.OpenDoc6(path, type, options, config, errors, warnings)`
- `model.ExportToDWG2(dxf_path, map_path, version, ...)`
- `model.Extension.SaveAs(pdf_path, version, options, ...)`

### 3. 属性映射表

根据PROGRESS文件，图纸模板使用 `R3_*` 前缀的属性名：

```

R3_CheckedBy → Eli

R3_DesignedBy → Eli
R3_DrawnDate → 2026-11-02
R3_Revision → R5
```
