# 工程图出图流程（Continue21 验证边界）

适用室内样本 PARAM-20261107121230852-8D5DE5。本文是工程图工具的流程草稿；Continue21 尚未取得有效 SLDDRW/PDF，不能称已验证出图方案，也不适用于户外柜。

## 输入和保护

- 从已绑定 attempt package 制作独立、无硬链接副本，闭文档重定位引用；冻结重定位后的 SHA。保护源包、母版、旧 attempt、历史 DXF 和证据。
- 独占新 SW2020；模型及全部本轮依赖 Windows 只读并用 ReadOnly 打开，逐份核对实际只读、完整路径、文件 SHA。warning1/128 或实际可写立即拦下；其它 warning 原值保留，局部出图结果不能改写整体健康 FAIL。
- 现有模板也复制到本轮工具目录并冻结，不修改安装模板。材料为空就写“未验证：缺 [原生材料值]”，不要猜钢种或签审人。

## 原生视图与一尺寸规则（待运行验证）

1. 沿已验证的只读内存展开准备路径，绑定本件正确平板型式与子折弯。门板左/右 ID 不互用；L/R 留在正确装配上下文，不进入 EditPart。
2. 新建 DrawingDoc，用 CreateFlatPatternViewFromModelView3 建立模型原生展开视图；核 IsFlatPatternView、ReferencedConfiguration 和完整模型引用路径。禁止用 DXF 导入或手绘冒充原生模型视图。
3. 每个展开只有一个真实关联总体尺寸，优先长边。用模型原生极值顶点、ModelToViewTransform、GetCorrespondingEntity 选取视图对应实体，再 AddHorizontalDimension2 / AddVerticalDimension2。核系统数值、GetOverride=false、IsDangling=false。宽×长作为有证据来源的规格备注，不新增第二条尺寸线或覆写数值。
4. 视图实际几何和已验展开对照，阈值 ±0.5 mm；该比较阈值不是工厂制造公差。L/R 完整实体 FAIL 应在图上明确披露。
5. 仅对新 Drawing 对象调用 SaveAs，路径必须是本轮预声明 SLDDRW/PDF。不得对模型 Save/SaveAs。用 ExportPdfData 导出 PDF。
6. 无保存关闭模型后，在新独立只读会话回读图纸：存储引用路径和 SHA、一个原生展开视图、一个不悬空无覆写的关联长边尺寸、规格与工艺限制备注。PDF还要视觉检查，不能以文件存在代替检查。

## 本轮实际错误和已编译修正

新 DrawingDoc 没有零件式活动配置对象。Continue21 首次尝试在 Scope 审计里对新图纸调用 ActiveConfiguration，NullReferenceException，中止于视图 API 前；没有产生合格图纸或 PDF。

最小工具修正：精确白名单仅接受本工具刚创建的 Drawing 对象或其预声明路径；只有已冻结模型文档才读取 ActiveConfiguration。新图纸行的活动配置写 null，不能伪造 Default。其它模型路径和实际只读门保持。修正仅编译，未完成运行验证。

清理不能依赖会再次抛异常的同一 getter。记录精确 PID、启动 ticks、EXE 身份和已创建 Drawing 身份；在原连接仍有效时无保存 CloseAllDocuments(true)、ExitApp，等待最多120秒。不可把可见桌面的窗口枚举缺失当进程退出。COM 不可用、无可操作窗口且 CAD 仍在时停止新会话，不强杀或开启第二个会话绕过。
