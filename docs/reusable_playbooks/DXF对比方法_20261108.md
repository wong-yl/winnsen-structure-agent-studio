# DXF 对比方法

适用范围：已执行的只读资料追溯、原生导出证据绑定和DXF解析对照。Continue18B提供了8份当前样本DXF及一个明确失败反例；成功接口和正确平铺内容分别核对。原始证据见 [RESULT_Continue18B_ThreeWay_20261108.md](<D:/Winnsen_Structure_Agent_Studio/data/review_portal_runtime/readonly_open_repair_20261105_1920/RESULT_Continue18B_ThreeWay_20261108.md>)。

## 先绑定同一个零件和版本

对比前至少记录 attempt、源模型路径及 SHA256（确认文件字节版本的校验值）、实际工作件、配置、平板特征/固定面、导出工具版本、DXF 路径与 SHA、导出时间及原始返回值。DXF 是二维交换文件，不能靠同名文件、日期接近、某个尺寸相同或镜向关系认定来源；若文件本身不保留可靠模型引用，必须用导出记录把它绑定到源模型。

主板面尺寸、完整下料轮廓、成形尺寸和激光打标面是不同对象。先声明测量对象和坐标定义，再相减。当前 H=2000 指顶部 Y，不是含调整脚总 Y 跨度约2060；门437×471.25是折弯尺寸，473.4×507.65才是左右门已测展开。

## 已执行的历史资料追溯

1. 只在已批准范围内清点文件，记录完整路径、mtime、大小和 SHA；按 SHA 去重，但保留每个来源路径。清点结果不是工程图身份通过。
2. 对原生图纸使用已冻结的闭文档 `GetDocumentDependencies2(path,false,false,false)` 读取存储引用。Continue18 查询1968组，真实图纸1967组返回非空数组，另1组是既有5字节锁标记。存储路径原值保留，不访问返回目标；它不等于依赖实际解析或加载成功。
3. 当前 attempt 的 SLDDRW/PDF/DXF/DWG 文件计数为0，存储引用当前 attempt 命中为0。因此未取得同版本二维标注，差值写“不可计算”，不能写“0”或“无超差”。
4. 对 PDF 提取文本并人工核对关键尺寸线，记录物理页号；零文本命中不等于图形中不存在。单页PDF的物理第1页与原文件名页号可能不同，必须明确。
5. 历史 DXF 共1716路径、1137独立SHA；TEXT/MTEXT/DIMENSION 注释读取0错误，8个独立文件有注释、共736条。这轮没有测轮廓包络，不能把注释读取成功写成几何对比通过。DWG只清点5份，未提取标注/引用。

这些数量属于已冻结的 Continue18 历史清单。本流程复用时只清点当前授权范围；户外柜继续搁置，R/U盘不得访问。

## 原生 DXF 对比步骤与已执行边界

以下步骤已在Continue18B用于原生导出与解析；未取得的加工用途、逐实体模型配准和工厂验收仍留为未验证。

1. 从已绑定的实际工作件/配置进行原生导出，记录调用参数、返回值、输出文件存在与非空、SHA及源文件前后校验。仅有返回true或文件名不够；独立副本的闭文档引用重定位应单列说明。
2. 读取DXF单位、实体和图层，区分切割轮廓、孔、折弯线、打标和文字；单位或图层含义不明就停在未验证。若单位元数据缺失，补明确的导出单位证据，不能静默猜mm。
3. 固定二维坐标与旋转映射，逐轴对比；若允许旋转90°，写明映射并保留原始轴向值，不能只排序长短边隐藏方向错误。镜像、比例和变换也要显式记录。
4. 用实际几何实体计算轮廓包络。LINE、圆弧、圆、polyline及其bulge、spline等必须按实际支持范围处理；不能只取端点漏掉弧极值，不能只靠文字或标注DIMENSION当轮廓真值。遇到未支持实体，记录类型、数量和受影响结论，不把它们静默跳过。
5. 同时报告“选定主板外轮廓包络”和“全部切割轮廓包络”，并记录图层/实体选择依据。折弯线、文字、工艺符号不能无说明计入切割包络；孔、开口、缺口和残留凸起不能因总长宽吻合而省略。
6. 将DXF轮廓与同阶段原生平板/主板面对应。当前左右门参考473.4×507.65；L只允许与限定主面533.7×1939.6比较，不能把它称为完整下料通过；R无参考实测，暂用L公式不可替代R。
7. 几何差值统一为“DXF−同版本原生实测”，图纸标注差值统一为“图纸标注−模型实测”。各轴分别报值、单位、公式、测量对象和阈值。当前0.5mm为报告单列阈值，工厂制造公差另需确认。
8. 保存可复核的原始解析JSON、实体/图层统计、包络、截图或叠图和计算工具SHA。存在同版本标注缺失、单位不明、轮廓不完整或几何原生门FAIL时，分别保留，不把一个有限比较扩成整机通过。

## Continue18B可复用的最小闭环

1. 独立副本在闭文档重定位后冻结SHA。保留原包、母版、旧attempt和保护清单。先过进程门；本轮自有CAD自然退出，仅处理已证明归属的孤儿monitor。
2. 原生导出options5与109分文件，返回true、非空文件及SHA同时记录；GetUnits原值与INSUNITS明确绑定。当前INSUNITS=4、原生swMM=0，不能仅凭MEASUREMENT或预期尺寸认mm。
3. 用冻结解析器读取实体、单位、图层及闭环；0层保持unknown，未分类加工意图不自动标切割。圆弧极值解析计算，端点连接容差0.001 mm；遇不支持曲线或拓扑歧义如实保留。
4. 主外闭环与全部几何包络分列。当前门两者均437×471.25，对473.4×507.65两轴−36.4；L的DXF X=1939.6、Y=533.7，必须明确以Y×X对宽×长。R约533.70855353×1939.60855353只有DXF证据。
5. 统计孔/切口候选和未闭合链，输出圆心、半径、实体handle。L的80圆形/15非圆和R的74圆形/15非圆不能以总长宽相似略过；8条CENTERX2只能作折弯/中心线线索。options109没有新增LINE不证明无凸台或没有其它曲线差异。
6. 输出“DXF−原生实测”和“DXF−公式”，超过0.5 mm单列；R缺原生值就留空。再核对所有输入SHA、临时属性恢复和锁，清单绑定工具/原生日志/解析器/结果版本。
