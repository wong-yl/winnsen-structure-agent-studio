# Codex 测量工具常见误判

本篇来自室内柜 Continue13–19 的实测与失败证据，供后续工具核对。它不修改模型，不授权将局部结果扩大为整机或工厂通过。

## 特征遍历顺序不是身份

Continue17 的 R 有同一组 53 个特征 ID，id131 只改变了遍历位置。按数组顺序逐项比较会误报身份变化。正确办法是拒绝重复/缺失 ID，再按 ID 集合及每个 ID 的名称、类型、所有者、父依赖、错误和各配置状态核对；无序的父 ID 集合排序后比较。不能因此忽略任何状态变化。

Continue19 第一次新工具的 53 项状态均通过；唯一允许变化的对象仍必须精确限定为平板型式7 id129 与其候选子草图 id128，且 `Default` 中状态不能改变。

## 名字叫边界框不等于证明没有实体影响

对 id128 至少要取原生证据：`GetOwnerFeature` 属于 id129 且 `IsSame=1`；原生直属子项唯一；`GetSpecificFeature2` 为草图；零实体面；草图原生线段组成同一草图的构造矩形；没有实体消费者。只凭“边界框2”的名字不能放行。

官方 `GetChildren` / `IGetChildCount` 是直接子依赖，不含孙级。目标对象的完整计数和返回数组一致为 0，再重复读取仍为 0，才可结合依赖图判断没有消费者路径。这个判断是限定的依赖图推断，不等于全树接口都健康。原生矩形和计数必须在本轮新会话实际取得；纯代码测试不能替代。

Continue19 第一次取证在无关 id12 遇到 `GetParentsCount=1`、`GetParents=null`，必须保留为不完整，不能当成 0 个父引用或 0 个消费者。若改用针对 id128 的完整直接子依赖证据，应保留原逆向 FAIL 和未覆盖范围，不回写旧结论。不能把目标对象自己的计数不一致也放行。

## 平板名称、整个实体、主板面是三种证据

- 处于 `DefaultSM-FLAT-PATTERN` 不代表子折弯已启用。门板的 12 个 `UiBend` 全部启用并通过限定范围检查后，才量到真正的 `473.4×507.65×0.8 mm`。
- L 全实体法向跨度约 10 mm，来源为 id156/304/309 的残留凸起，不能写成材料厚度 10 mm。
- 两个主平行面的厚度与面内包络即使通过，也不等于整个实体的厚度/平行面门通过。主板面的证书必须绑定同一当前实体、固定面、原生边端点和精确极值，不能任意剔面或挑一个候选薄片。
- Eli 对 L 仅限定通过主板面尺寸；完整实体几何门仍 FAIL。R 必须取得自己的面与特征证据，不能套用 L。

## API 事件不是文件清单

Continue19 左门方法二在 `ExportFlatPatternView` 调用后，旧对象 `GetPathName` 抛 `RPC_E_DISCONNECTED`，未记录完整 API 返回，也未到 `SaveAs`。但 CAD 退出后实际有一份 DXF。

因此，成功 event 缺失不等于文件不存在；导出进行中目录为空也不是最终证据。应收尾查目录，再核对预定新路径、时间、SHA、单位和几何，同时保留 API FAIL。该左门文件已证明尺寸、毫米和 12 条折弯线，但原运行门没有通过，右门新文件仍缺。

## 数值不要跨层替代

- 存储 K 因子不等于实际生效折弯补偿。板厚表、继承或覆盖状态未知时，记录未知，不能用原始 K 或另一零件的扣除量补齐。
- warning 是位值；`34` 不能写成 34 个警告文件，`32` 不能写成 32 个 NeedsRegen 文件。实际只读、bit1、warning128 和零 warning 健康门分开记录。
- 文件 SHA 不变证明磁盘字节未变，不能证明内存 `saveFlag=false`，也不能代替几何验收。
- 二维 DXF 不能提供厚向和源特征归属。尺寸一致可作旁证，不能替代原生展开和工艺验收。

## Continue19 的 R 实际结果

第二种限定证明已完成：id128 的原生 owner 为129且 `IsSame=1`，直属唯一草图的4条自有构造线构成共面闭合矩形，零实体面；读取矩形前后完整的直接子依赖均为0。53项按ID集合和各ID状态核对通过，旧generic FAIL和无关id12的逆向取证FAIL均保留。

展开后的同一当前钣金实体264/264个面采集完整。两张主板面为face122/135，面积约1012493.5804/1012418.1822 mm²；间距0.8 mm、法向相反，原生边端点达到同一实体U/V四个极值。实测主板面 `533.70855353×1939.60855353 mm`，比推断对称公式 `533.7×1939.6` 两轴各大约 `0.00855353 mm`，与18B R DXF吻合。

完整实体法向仍约10 mm，厚度门和平行面门仍FAIL。主板层外6个平行小面，每面约12.5664 mm²，位于固定面上方9.8或10 mm；原生归属均为id81 `MirrorStock`（箱体竖隔板R参数源_镜向）。这些局部残留没有扩大已证主板面尺寸；实际工艺用途未证明，不能只按名字套用L的凸台特征。没有抑制、剔除实体或修改公式。

R原始钣金参数为厚0.8、id90内R0.7366，四个OneBend约R0.5；存储K=0.333333。实际生效补偿尚未证明，`ExcludedFaces` 原始COM错误和完整工具exit1均保留。主板面尺寸证书不能把这些FAIL改写成通过。

离线证书也可能误判：原生采集器为避免重复读取COM，把平面边端点放在 `planarLoops`，并将 `edgeVertices.collectedViaPlanarLoops` 标为true；旧离线脚本仍读 `edgeVertices.edges` 会报KeyError。只适配已采字段并核对完整计数即可，不能重开CAD或降低几何条件。本轮保留旧脚本与失败记录，新增字段适配脚本，没有第三种CAD修法。
