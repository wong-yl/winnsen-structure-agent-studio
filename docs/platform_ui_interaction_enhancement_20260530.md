# Winnsen Structure Agent Studio 平台交互增强说明

日期：2026-05-30

## 当前结论

子智能体这轮做的是“协作平台增强草案”，不是 CAD 自动生成闭环。代码可以保留为平台交互方向的原型，但不能把它理解成已经能稳定生成生产级钣金柜门模型。

当前可用边界：

- 工程师登录后可以继续下载 16029 LMS / SML / DUAL 三个审核包。
- 平台新增了柜门提示词工作台，用于把自然语言整理成门板、门高、锁具、铰链、加强筋、开孔等参数草案。
- 平台新增了浏览器内参数化预览，用于确认门序、门板比例和五金意图；左右列不同门高序列（例如左 6/4/2、右 2/4/6）可以分列显示。
- 平台新增了结构工程师交互区，用于整理审核点、截图路径、模型路径、验证记录和可复制的审核提示词。
- Studio 前台模型生成页可以下发本地生成任务；任务生成输出后，任务详情和生成反馈区会提供“下载结果包”，下载内容为该任务输出目录的 ZIP。
- 登录台可以保存 3D 建模任务草稿到本机运行数据目录，并通过 `tools/process_16029_review_generation_queue.mjs` 自动生成 CAD worker 任务包、回写下载入口。

当前不可当成已完成的能力：

- 不能直接根据提示词释放生产模型。
- 不能自动生成生产图纸、展开图、公差或喷涂后间隙结论。
- 不能自动确认锁孔、铰链孔、插销和加强筋生产尺寸。
- 浏览器预览只是参数化参考预览，不是真实 SolidWorks/STEP 几何预览。
- 下载结果包是工程参考模型输出包，不等于生产图纸释放包。

## 已实现入口

- `apps/web/src/App.tsx`
- `apps/web/src/App.css`
- `tools/serve_16029_review_downloads.mjs`

## 平台整理原则

- 代码可以进入平台原型主线，但必须标注“草案/预览/需工程师确认”。
- 运行数据不进入 Git 主线，`data/review_generation_requests/` 仅作为本机任务草稿目录。
- CAD 生成物、Pack and Go、历史试错包继续留在忽略范围内，不混入代码提交。
- SolidWorks 2020 仍是当前工程师审核软件主线。
- FreeCAD 只能作为内部参数化和证据生成工具，不能作为工程师审核软件口径。

## 后续接 CAD 的路线

1. 提示词解析输出稳定 schema：柜体尺寸、门序、门板规格、五金要求、证据缺口、风险提示。
2. 生成任务必须先进入 `pending_engineering_evidence` 或 `draft_pending_cad_worker` 状态。
3. 登录台队列当前先生成 `cad_worker_payload_package`，用于下载任务包和交给后续 CAD worker；这不等同于已经生成生产级 CAD 模型。
4. CAD worker 只接受已确认的门板、锁、铰链、插销、加强筋规则输入。
5. 输出必须带截图、bbox、组件清单、规则来源和人工审核状态。
6. 生产释放前仍要结构工程师确认锁啮合、门缝、铰链、开孔、折弯和装配路径。
