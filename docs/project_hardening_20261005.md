## 模型与历史交付边界

新模型必须按包内零件文件、使用配置、装配实例和实体身份核对检查覆盖；缺少、重复或未知的展开记录与实体记录均拒绝发布。检测对按实体边界重新计算，完整且无接触的模型允许零接触；普通零件不要求制造展开。隐藏参考模型须有明确身份与隐藏证据，不能任意排除隐藏结构件。

此前四份已交付参数化模型按固定任务编号、发布时间、生成目录与压缩包 SHA-256 保留下载，并继续检查文件和阶段证据。它们的 `coverageVerified=false`、`coverageStatus=legacy_unverified`，不表示通过新增覆盖验收。历史证据不补写、不重标为完整通过。新生成不能选择这一兼容入口。

验收仍仅用于静态结构工程辅助，不替代工程师接收、制造公差或开门运动验收。
