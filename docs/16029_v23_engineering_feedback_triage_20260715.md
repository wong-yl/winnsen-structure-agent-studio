## 3. T01 / T02 / T04 精确根因定位

### 3.1 共同根因

这三项不是装配随机偏移，也不是 v23 Pack-and-Go 新增的问题。根因是 1000W 金标准转换为 740W `v37` 壳体时混用了两种不兼容的宽度变换：

- 门轴、调节脚、门框左右立柱等侧边对象按左右各 `130 mm` 向内平移；
- 门框下横梁、底座底板等横向整板按总宽比例整体缩放；
- 整体缩放同时移动了侧边孔、缺口和边缘，破坏了它们与平移对象之间原有的局部接口关系。

生成链路证据：

1. v23 与 v9 种子中，T01、T04 的圆柱/孔槽几何数组完全一致；T01 干涉体积同为 `67.858401 mm³`，T04 左侧同为约 `115.083762 mm³`。
2. v9 由 v8 对 `candidate_16029_740W_gold_shell_frame_shelf_only_v37.SLDPRT` 的 123 个实体拆分后，以零位变换重新组装；拆分零件包络与 v23 一致。
3. `v37` gate 明确记录 `left_translated=39`、`right_translated=42`、`full_width_scaled=11`，但当时只验证了对象数量和包络，没有验证孔轴同心、边缘间隙及实体干涉。

因此，不能通过移动门、门轴、调节脚或门框去迁就错误板件；应修复下一候选中的横梁/底板宽度转换方式。

补充识别：候选中的 `底座焊接_body082` 实际来源是 1000W 金标准的 `门框 下`，在角色分类时被误归为底座件。

1000W 金标准实测：

- 门轴中心与 `门框 下` 孔中心均为 `X=-467、Z=-7 mm`；
- 销半径 `3.0 mm`、孔半径 `3.1 mm`；

正确目标：740W 下横梁外宽保持目标尺寸，但两端门轴孔应随门轴侧边基准平移至 `X=±337、Z=-7 mm`，不能随整条横梁同比例缩放。`0.1 mm` 径向源值仅作金标准复现依据，喷涂和制造间隙仍需结构工程师确认。

### 3.3 T02 调节脚—底座底板让位

候选实测：

- 四个螺母/调节脚轴线为前侧 `X=±335、Z=-74.5 mm`，后侧 `X=±335、Z=-500.5 mm`；
- `底座焊接_body113` 在这些轴线上方仍有实体板料；以前左螺母为例，最近点为螺母 `(-335, 12.8, -68.5)` 与底板 `(-335, 27, -68.5)`，即同一 X/Z 上方直接有板料；
- 当前最小距离 `14.2 mm` 只是高度方向距离，不代表存在装配/调节让位；
- 四个位置为左右、前后对称的同类问题，不是单个实例装配偏移。

1000W 金标准关系：

- 调节脚轴线 `X=±465 mm`；底板边缘 `X=±479 mm`，轴线距边缘 `14 mm`；
- 前左位置最近底板边界点为 `X=-478.2 mm`，不是位于螺母轴线正上方，说明原侧边让位轮廓保持在边缘区域；
- 740W 侧边平移后的对应目标应为调节脚 `X=±335 mm`、底板边缘约 `X=±349 mm`，继续保持 `14 mm` 相对关系；
- 当前候选底板却被整体缩放到 `X=±370.0955 mm`，每侧比上述侧边平移目标宽约 `21.0955 mm`，从而把板料移到调节脚上方。

正确目标：从 1000W 金标准底板恢复侧边让位轮廓并按每侧 `130 mm` 平移，只调整中间跨距；不能在未知工艺尺寸时随意新增圆孔。让位孔/开口最终尺寸、工具空间和喷涂补偿仍由结构工程师确认。

## 4. 可执行整改要求

### T01 底座孔与门轴销不同心

风险：门无法正常装配或转动，可能导致门板卡滞、异常受力和门缝漂移。

整改动作：

### T02 调节脚与底座孔不匹配

风险：调节脚无法装配、受力偏心或安装后顶碰底座。

1. 核对调节脚螺杆中心、安装面和底座孔中心。
2. 检查候选中的全部 8 个调节脚实例，确认问题是单点还是阵列/源件共性错误。
3. 若底座缺少孔，补充与螺杆、装配工具和喷涂余量相匹配的通孔/让位；若仅位置错误，修正基准或装配变换。

验收：全部调节脚均可装拆和调节；螺杆不碰孔壁；底座局部强度和支撑面不因开孔被削弱。孔径及间隙值由结构工程师确认。

### T03 锁控维护条下端折弯边与底座干涉

验收：维护条对全部底座实体精确干涉为 `0`；与 `body082` 当前金标准复现间隙为 `0.2 mm`；维护条可正常装拆且折弯边保持原形。`0.2 mm` 是否足以覆盖喷涂和装配公差仍由结构工程师确认。

### T04 门框与底座定位脚/主体接口错误

验收：定位脚均能自然进入对应位置；门框基准面落位；与 body113 实体干涉为 0；门框直线度及门口尺寸复核通过。
