# 16029 Left Shelf V74 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 生成一个一次性 V74 左层板候选，并在 reopen 后同时满足 `body_count=1`、`K=0.4`、`FlatPattern` 存在、外形包络为 `429 x 8.4 x 18.7 mm`。

**Architecture:** 不修改 V68-V73，也不基于 V71 做后置 DeleteBody。复用 V70 的空白零件构造流程，在转换前只有一个完整 L 实体；调用 `InsertConvertToSheetMetal2` 时使用 `FindBends=true`、`KeepBody=false`，再复用 V71 的 K 因子 override/custom allowance 路径。所有运行产物只进入新的 V74 `tmp/` 和 `data/` 路径。

**Tech Stack:** C#/.NET Framework 4、SOLIDWORKS 2020 Interop、PowerShell。

**隔离决定:** 当前仓库不是 linked worktree，且 V68-V73 关键基线是未跟踪文件。不得新建缺失这些基线的 worktree；只允许新增下列 V74 文件，不允许修改或撤销任何现有文件，不允许 commit/push。

---

### Task 1: V74 builder

**Files:**
- Create: `workers/solidworks_tools/Build16029LeftShelfSingleBodyConvertV74.cs`
- Read-only references: `Build16029LeftShelfAdjustedSideFaceLFoldedSolidConvertV70.cs`, `Retune16029LeftShelfV70CandidateKOverrideV71.cs`

- [ ] **Step 1: 保留 V70 的单实体 L 形构造前置检查**

转换前必须记录并断言：

```csharp
beforeBodyCount == 1 &&
Near(beforeXmm, 429.0) &&
Near(beforeYmm, 8.4) &&
Near(beforeZmm, 18.7)
```

- [ ] **Step 2: 使用单实体转换参数**

关键调用必须精确为：

```csharp
features.InsertConvertToSheetMetal2(
    ThicknessM,
    false,
    true,
    BendRadiusM,
    0.0,
    (int)swSheetMetalReliefTypes_e.swSheetMetalReliefRectangular,
    0.5,
    0,
    0.0,
    false)
```

其中第 3 个参数是 `FindBends`，第 10 个参数是 `KeepBody`；本机 SW2020 Interop 已通过反射确认参数名和位置。

- [ ] **Step 3: 设置并读回 K=0.4**

复用 V71 已通过的 `ISheetMetalFeatureData`、`CustomBendAllowance`、`SetOverrideDefaultParameter2` 和 `ModifyDefinition` 路径。不得仅修改内存值；保存前和 reopen 后都必须读回 `KFactor=0.4`、override=true、custom allowance K=0.4。

- [ ] **Step 4: 严格验证转换后和 reopen**

PASS 谓词必须同时包含：

```text
body_count == 1
envelope == 429 x 8.4 x 18.7 mm
has SheetMetal
has SolidToSheetMetal
has FlatPattern
K == 0.4
thickness == 0.8 mm
owned SolidWorks exits
no SLDWORKS/sldProcMon remains
```

任一失败时仍写 evidence，但状态必须是 FAIL/INCOMPLETE，不得输出 PASS。

- [ ] **Step 5: 输出合法 JSON evidence**

固定路径：

```text
data/locker_16029_shelf_min_native_v74_single_body_convert_evidence.json
tmp/locker_16029_left_shelf_v74_single_body_convert/disposable_left_shelf_single_body_convert_v74.SLDPRT
```

JSON 至少记录输入/输出哈希、转换参数、before/after/reopen body 数和包络、特征列表、K 读回、保存错误/警告、进程 PID 与退出状态。
