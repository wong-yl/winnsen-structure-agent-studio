# 16029 V29 工程反馈修订设计

日期：2026-07-30  
基线：`v43-int-v28-five-feedback-fix-r1`  
目标版本：`v43-int-v29-three-feedback-fix-r1`

## 1. 目标

在不扩大上游参数传播范围、不破坏已验证接口的前提下，处理当前反馈轮次的 3 条工程反馈，并形成可复核、可回退的 SolidWorks 2020 原生模型交付包。

当前反馈轮次共 3 条，未发现新增反馈：

1. `V28-Q-20260730T002216-AF5F55`：门框上拉铆孔位 250 改 200。
2. `V28-Q-20260730T002634-6C3A07`：底座底板敲落孔与加强筋焊接螺母不同心。
3. `V28-Q-20260730T002821-4D9AD8`：底座底板与门框下拉铆孔不同心。

## 2. 推荐方案

### 2.1 门框上拉铆孔

修改 `门框 上.sldprt` 的 `草图5`：

- `D2@草图5`：250 mm → 200 mm
- `D3@草图5`：250 mm → 200 mm

目标是将 4 个孔中心从 `-375 / -125 / 125 / 375 mm` 调整为对称的 `-300 / -100 / 100 / 300 mm`，保持孔径、边距和其余特征不变。

### 2.2 底座底板敲落孔

修改 `底座底板.sldprt` 的 `草图9`：

- `D1@草图9`：590 mm → 670 mm
- 保持 `D2@草图9 = 426 mm`

目标是将 4 个敲落孔的横向中心从 `±295 mm` 调整为 `±335 mm`，与两侧加强筋焊接螺母孔中心对齐；纵向位置和孔径保持不变。

### 2.3 底座底板与门框下

不修改现有对应孔位。V28 原生几何复核显示：

- 底座底板对应孔中心：`x = -125 / 125 mm，z = -25 mm`
- 门框下对应孔中心：`x = -125 / 125 mm，z = -25 mm`
- 两组孔轴偏差：`0 mm`

因此不在未确认孔组的情况下盲目移动。V29 交付证据中保留该接口的精确同心检查结果；若工程师指的是截图中的另一组孔，要求其在平台补充具体孔位标注后再单独修订。

## 3. 实施边界

- 从 V28 原生 CAD 复制生成独立 V29 工作目录，V28 不覆盖。
- 只修改上述 3 个驱动尺寸中的确定项，不改上游主控模型、孔径、板厚、材料或装配层级。
- 修改前保存目标零件备份。
- 使用 SolidWorks 原生 API 修改、重建并保存，不直接改写二进制文件结构。
- 不把未确认的第三组孔位猜测性纳入模型修改。

## 4. 验证标准

V29 必须同时满足：

1. `门框 上.sldprt` 的 `D2@草图5`、`D3@草图5` 均为 200 mm。
2. `底座底板.sldprt` 的 `D1@草图9` 为 670 mm，`D2@草图9` 仍为 426 mm。
3. 底座底板 4 个敲落孔与两侧加强筋对应螺母孔轴偏差为 0 mm。
4. 底座底板与门框下已识别的两组拉铆孔轴偏差仍为 0 mm。
5. 相关零件、子装配和总装配重建无错误。
6. 总装配引用完整，无缺失文件和工作目录外引用。
7. 原生钣金特征及展开能力保持有效。
8. 生成 V29 证据、交付清单、压缩包，并把下载与反馈入口更新到当前平台。
