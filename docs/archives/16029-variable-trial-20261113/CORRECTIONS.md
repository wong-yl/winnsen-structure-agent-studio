# 已确认勘误与未关闭问题

本说明仅纠正证据解释，不修改原报告、源码、CAD 或 DXF。原报告保存在同目录 `evidence/`。记录日期：2026-11-13。

1. **旧重量 `0.00` 不能归因于“仅出现在未完成失败批次”。** 原总报告及重量报告的这项归因错误。已完成、`code=0` 的 T3 `338f953c` 与 T4 `f58333e9`，仍存在同一路径、同配置、不同装配实例读取“重量”为正常值与 `0.00` 的情况。例如 T4 case3 的 `crossbar_R_1=184.23`、`crossbar_R_2=0.00`，均标记 `status=2, wasResolved=true`。装配读取路径与独立零件诊断路径不同是事实；具体根因仍未验证，不能声称逐件重建一定能修复。见 `excerpts/` 内的 T3/T4 case 摘录。

2. **两轮重量诊断的样本口径应为 32 次配置观察。** 4 个零件身份各取 T3/T4 来源，共 8 个目标文件；每个目标读取 2 个配置，每轮 16 条、两轮 32 条。不是 32 个独立文件，也不是“每轮 8 条、共 16 条”。独立冷读稳定不能关闭整装配属性异常。原 `weight-comparison.json` 的 `targetCount=16` 按配置行计数。

3. **材料字段缺失与密度差异真实存在，不能把稳定性等同于制造重量正确。** 此次重量样本中，`Default` 材料为冷轧钢板、密度约 `7870 kg/m³`；`DefaultSM-FLAT-PATTERN` 的材料名和材料库为空、密度约 `1000 kg/m³`。只能确认这些样本的读数，不能推导 SolidWorks 所有无材料配置均按水密度回退。右门板材料为空、`UNSPECIFIED`，材料工艺资格仍未确认。

4. **`structure_1000_8` 缺少的是精确名为“重量”的属性。** T4 case1 的 `箱体竖隔板R_parametric.SLDPRT` 两配置材料字段为空，配置级属性为空；文档级仍有 `Weight`、`单重`、`质量`，解析值均为 `6.386`。不能写成没有任何质量信息。未验证：缺该零件独立质量、密度及显示单位读回，不能擅自给 `6.386` 补单位。

5. **T3 结构验收仍未通过。** case1 为 50 个干涉体、22 个组件对，总相交量约 `16.1454685 mm³`；case2/case3 各 65 个干涉体、30 个组件对，约 `397.2464391 mm³`。这些不是可以整对忽略的接触项。保留原结构完成测量的用户决定继续有效；本次未实施结构整改。

6. **`BEND_DED` 尚未作为可变工艺参数闭环。** 当前代码写入固定 `1.4 mm`，未在方程中直接绑定折弯扣除实体特征；继承语义未独立验证。该问题不单独否定已测宽高变化的展开几何，但不能宣称扣除变化已验证。制造正反面与折弯方向仍未确认，`dxfDirectionPass=false`；几何检查通过不能替代工艺资格。
